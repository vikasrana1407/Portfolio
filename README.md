# Vikas Rana — Portfolio

A responsive, single-page portfolio introducing my work across AI/ML, Python, web development, and automation.

## Highlights

- Responsive portfolio layout with section-based navigation
- Rotating hero text, animated neural-particle canvas, and skill-category filters
- Project, skills, and contact sections
- Built with plain HTML, CSS, and JavaScript; no package manager or build step is required

## Run locally

Open `index.html` in a browser, or serve the repository root over HTTP:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Files

- `index.html` — page structure and portfolio content
- `style.css` — responsive visual design
- `app.js` — navigation, rotating text, filters, and canvas animation

## Note

The contact form currently displays a client-side success message; it does not deliver email. Connect it to a backend or a form provider before relying on it for messages.
